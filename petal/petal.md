# Petal — Playtest Report

**Developer:** 13-23

**Platform:** itch.io

**Genre:** Point-and-click narrative/horror (mouse-only)

**Tester:** Loïc Alexandre (Wattmole)

## Summary
Full playthrough of a mouse-only point-and-click narrative game (75% of planned content complete at time of testing). One repeatable-interaction bug found; otherwise a positive experience with the atmosphere and pacing.

## Issues Found

| # | Severity | Area | Description |
|---|---|---|---|
| 1 | Medium | State management | Certain one-time interactions can be repeated indefinitely: inspecting the house photo replays its full sequence every time, and talking to Margarida after she's already given the petal repeats the same dialogue and re-grants the same item instead of progressing or acknowledging it was already given. |

## Positive Notes
- Camera angles and atmosphere praised for creating tension and unease.
- Story pacing felt natural throughout.
- Notable scope achievement: ~75% of the game built using only mouse input.

## Developer Response
The developer attributed the repeat-interaction bug to messy underlying code, and noted they were taking the feedback into a new project set in the same universe.
